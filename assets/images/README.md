# Images Directory

This directory is for storing images used in the Green Tech Solutions Enterprises website.

## Placeholder Images

Since this is a static website demo, we're using placeholder images from Unsplash. In a production environment, you would replace these with your own high-quality images.

## Recommended Images to Add:

1. **Hero Background**: Agriculture field image for the home page hero section
2. **Product Images**: High-quality photos of fertilizers, pesticides, and agricultural medicines
3. **Company Logo**: Green Tech Solutions Enterprises logo
4. **Team Photos**: If you want to add an "About Us" section later
5. **Testimonials**: Farmer testimonial photos if needed

## Image Optimization:

- Use WebP format for better performance
- Compress images to reduce file size
- Use responsive images with srcset for different screen sizes
- Lazy load images for better performance
